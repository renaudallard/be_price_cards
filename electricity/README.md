# Electricity cards

The tariff cards homeassistant_be_electricity_prices parsed, kept as the assets of
the `electricity-<YYYY-MM>` releases of this repository and named by their SHA-256.

- `coverage.md`: per contract and region, the months held, each linking to its card.
- `pdfs.md`: every kept card by release, with the contracts and months it was read for.

The parsed cards themselves are the `archive` branch of
https://github.com/renaudallard/homeassistant_be_electricity_prices.
